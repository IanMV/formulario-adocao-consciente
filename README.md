# Site web para formulário de adoção consciente

## Seção de entrada.

**Capa de fundo:** foto de um cachorro

**Legenda:** Uma adoção responsável começa com uma escolha consciente.
O amor por um animal é muito importante, mas cuidar dele exige tempo, dedicação, planejamento financeiro e responsabilidade. Esse site foi desenvolvido para ajudar pessoas a descobrirem se estão preparadas para adotar um animal, considerando suas condições financeiras, rotina, moradia e capacidade de oferecer os cuidados necessários.
Nosso objetivo é conscientizar a população e contribuir para a redução do abandono animal, incentivando adoções mais responsáveis e lares mais seguros.

**Botão:** Inicie a avaliação.

O botão levaria o usuário até o formulário.
